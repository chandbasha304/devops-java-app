The Three Security Pillars of HTTPS

Interactive demonstration and live browser UI verification of Confidentiality, Integrity, and Authentication.

🔒
1. Confidentiality
Privacy Guarantee: Eavesdroppers intercepting raw network packets only see encrypted random-looking ciphertext. Cleartext passwords, session tokens, and JSON payloads remain invisible.
Cipher:AES-256-GCM / 256-bit
Key Size:2²⁵⁶ combinations
🛡️
2. Integrity
Tamper-Proof Guarantee: Every packet carries an AEAD Authentication Tag (GMAC). If an attacker modifies even a single bit in transit, the browser immediately drops the connection with ERR_SSL_BAD_RECORD_MAC.
Mechanism:AEAD Tag (128-bit)
Detection:100% Instant Abort
📜
3. Authentication
Identity Verification: Cryptographically proves you are connected to the genuine server and not an impersonator. Verified via RSA-2048 / ECDSA digital signatures signed by trusted CAs.
Algorithm:RSA-2048 / SHA-256
Identity:Common Name (CN) / SAN
